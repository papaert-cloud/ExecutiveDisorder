🎮 Executive Disorder

Unity 6 Game Project

📋 Project Overview

This repository contains the source code and assets for the Executive Disorder Unity game project.

Executive Disorder is a decision-making card game where players navigate political scenarios, managing resources like popularity, stability, media relations, and economic factors.

🎯 Game Features

  • Decision Card System: Choose from multiple options that affect game resources
  • Character Selection: Play as different political characters with unique attributes
  • Media Reactions: Your decisions trigger various media responses
  • Multiple Endings: Reach different endings based on your performance
  • Resource Management: Balance popularity, stability, media, and economic factors

🛠️ Technical Stack

Game Engine

Unity 6

Language

C#

Platforms

Windows, Linux, WebGL

IDE

Visual Studio

📁 Repository Structure

  • 📂 Assets/ - Game assets, scripts, scenes, prefabs
  • 📂 ProjectSettings/ - Unity project settings
  • 📂 Packages/ - Unity package dependencies
  • 📂 app/ - Flask web application (this page)
  • 📂 kubernetes/ - Kubernetes deployment configs
  • 📂 terraform/ - Infrastructure as Code
  • 📂 scripts/ - Utility and bootstrap scripts

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/papaert-cloud/ExecutiveDisorder.git

2. Open in Unity Hub

Open the project in Unity 6 using Unity Hub

3. Build the Project

Check Build Settings and ensure all required scenes are in the "Scenes In Build" list

4. Run or Deploy

Build for your target platform (Windows, Linux, or WebGL)

📊 Game Data

The game includes extensive JSON data files for:

  • Characters: Political characters with unique attributes
  • Decision Cards: Multiple-choice scenarios with consequences
  • Media Reactions: Dynamic media responses to decisions
  • Endings: Various game endings based on resource levels

📝 Note

This is a Unity game project that requires Unity Editor to run and build. This web page serves as project documentation and information. To play the game, you need to build it from the Unity project.
