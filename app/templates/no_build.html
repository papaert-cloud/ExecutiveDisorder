📝 How to Build WebGL in Unity

Step 1: Open Project in Unity

Open this Unity project in Unity 6 on your local computer

Step 2: Configure Build Settings

Go to File → Build Settings

  • Select WebGL as the platform
  • Click "Switch Platform" if needed
  • Ensure all required scenes are added to "Scenes In Build"

Step 3: Configure Player Settings

Click "Player Settings" and configure:

  • Set compression format to Disabled or Gzip (Brotli may not work on all servers)
  • Disable "Data Caching" under Publishing Settings

Step 4: Build

Click Build and choose a folder (e.g., "WebGLBuild")

Unity will create files including:

  • index.html
  • Build/ folder containing .wasm, .data, .js files

📤 How to Upload to Replit

Step 1: Locate Build Files

Find the WebGL build folder on your computer

Step 2: Upload to Replit

Upload all files from your WebGL build folder to:

app/webgl/

The structure should look like:

app/webgl/index.html
app/webgl/Build/...

Step 3: Reload

Once uploaded, refresh this page. The game will automatically load!
