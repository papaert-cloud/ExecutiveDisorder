# 🎮 Executive Disorder™

**A satirical political decision-making game built with .NET 9**

> *Lead by Absolute Chaos. Rule with Memes.*

---

## 📖 Overview

**Executive Disorder** is a console-based political satire game where you play as the President of the United States, making critical decisions that affect four key resources while navigating relationships with eight colorful political characters. Every choice has consequences, and chaos is inevitable.

### Key Features

- **101 Decision Cards** - From nuclear crises to absurd policy debates
- **8 Political Characters** - Including the Iguana King, Mascot Bot, and the 45th Executive
- **4 Core Resources** - Manage Popularity, Stability, Media Trust, and Economic Health
- **10 Unique Endings** - Based on your choices and resource management
- **Dynamic Consequences** - Decisions cascade and affect future events
- **Crisis Escalation** - Watch as small problems spiral into constitutional crises

---

## 🎯 Game Concept

You've just been sworn in as President. A nuclear submarine has been detected in territorial waters. The Joint Chiefs await your orders. The world is watching.

**This is your first decision. It won't be your last.**

Navigate political scandals, absurd proposals, conspiracy theories, and actual crises while trying to keep the government functioning (or not). Will you be a democratic hero? An autocratic emperor? Or will you accidentally start an intergalactic alliance?

## 🎮 How to Play

### Prerequisites

- **.NET 9 SDK** - [Download here](https://dotnet.microsoft.com/download/dotnet/9.0)
- **Windows Terminal** (recommended for best experience)

### Running the Game

```bash
# Clone the repository
git clone git@github.com:papaert-cloud/ExecutiveDisorder.git
cd ExecutiveDisorder

# Build the project
dotnet build

# Run the game
dotnet run --project ExecutiveDisorder.Game
```

### Gameplay

1. **Read the Situation** - Each turn presents a decision card with context
2. **Consider Your Options** - 2-4 choices per card, each with consequences
3. **Make Your Decision** - Choose wisely (or don't)
4. **Watch the Chaos Unfold** - See immediate effects and cascading consequences
5. **Survive 100 Days** - Or until resources are depleted

## 🌟 Game Systems

### Resources (0-100%)

| Resource | Icon | Description |
|----------|------|-------------|
| **Popularity** | 👥 | Public approval rating |
| **Stability** | 🏛️ | Government/institutional stability |
| **Media Trust** | 📺 | Press and media relations |
| **Economic Health** | 💰 | Economic indicators |

### Crisis Levels

- 🟢 **Normal** - Everything's fine (for now)
- 🟡 **Warning** - One resource critical
- 🟠 **Severe** - Two resources critical
- 🔴 **Critical** - Three+ resources critical
- ⚫ **Game Over** - Any resource depleted
